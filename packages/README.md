# Shared packages

Reusable TypeScript packages shared by applications live here. Packages must
not contain deployable application entrypoints.

| Directory | Purpose |
| --- | --- |
| `api-client` | Typed HTTP client for CabinSentinel APIs |
| `auth` | Shared authentication and portal guards |
| `contracts` | Product and API contracts |
| `design-tokens` | Shared visual tokens |
| `domain` | Frontend domain helpers |
| `test-fixtures` | Shared frontend test fixtures |
