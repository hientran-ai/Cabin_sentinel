# cockpit-web

End-to-end demo page: car cockpit + owner phone + evidence panel reading one backend session (`/api/v1/e2e`).
`?mode=playground` opens the original mock cockpit (not end-to-end, labelled as such).
See `docs/OEM_E2E_V1_RUNBOOK.md`. The car model is Car Concept by Khronos Group (CC-BY 4.0, see `public/models/CarConcept-LICENSE.md`).

```bash
npm run dev:cockpit   # from the repository root; needs the backend on :8000
```
