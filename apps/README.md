# Applications

Deployable user-facing applications live here.

| Directory | Purpose | Main command |
| --- | --- | --- |
| `owner-web` | Owner and caregiver web portal | `npm run dev:owner` |
| `operations-web` | Admin and safety operations portal | `npm run dev:operations` |
| `mobile` | Mobile client | `npm run start:mobile` |

Shared code must be placed in `packages/`; backend code belongs in `services/`.
