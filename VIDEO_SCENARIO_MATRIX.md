# Video scenario matrix

**Source:** supplied `scenario_manifest.json`; videos live in `apps/cockpit-web/public/samples/scenarios/videos/`. The model was run on 10 frames per original MP4 using the existing `yolov8n.pt` weights and the frontend's JPEG resize (640 px wide, quality 80). Manifest visual notes are not detections. The pack has no independently annotated frame/box ground truth, so precision/recall and cabin-localization accuracy are not measurable here.

**Missing visual scenarios:** rear-facing/partly occluded child, fully blocked camera, pet alone, adult intentionally sleeping in Camping Mode, driver exits while child remains, sensor conflict, and network disconnect/reconnect. Use deterministic labelled simulated sensor fixtures for rule tests; obtain real annotated footage before claiming vision coverage. Do not fabricate footage or boxes.
